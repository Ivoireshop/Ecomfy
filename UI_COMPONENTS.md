# Ecomfy UI Components Library

Inventaire des composants d'interface utilisateur réutilisables d'Ecomfy.

---

## 📦 Liste des Composants Standardisés

- **`Button`** (`src/components/ui/button.tsx`) : Bouton interactif avec retours 3D (`btn-interactive`), variantes default, secondary, outline, destructive, ghost.
- **`StatCard`** (`src/components/ui/StatCard.tsx`) : Carte de statistique KPI avec icône, badge de pourcentage et lueur émeraude.
- **`EmptyState`** (`src/components/ui/EmptyState.tsx`) : Composant d'état vide avec illustration, message clair et action CTA.
- **`Card`** (`src/components/ui/card.tsx`) : Conteneur à coins arrondis avec ombres douces et support `.card-interactive`.
- **`Input`** (`src/components/ui/input.tsx`) : Champ de formulaire avec anneau de focus lumineux émeraude.
- **`SEO`** (`src/components/seo/SEO.tsx`) : Gestionnaire SEO pour l'injection des balises canonical `ecomfy.cloud`, OpenGraph et JSON-LD.
